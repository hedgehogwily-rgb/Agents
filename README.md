День 6 — LangSmith tracing и наблюдаемость

🎯 Цель дня
Сделать работу агента прозрачной и наблюдаемой через LangSmith и логирование.

📋 Задачи
1. 📊 Подключить LangSmith для trace execution или подготовить проект так, чтобы LangSmith включался через конфиг без переписывания архитектуры
2. 📝 Логировать ключевые этапы:
   - chosen node
   - chosen action
   - tool call
   - observation
   - updated state
3. 🔍 Разобрать минимум 3 сценария:
   - успешный
   - частично успешный
   - ошибочный
4. 🧪 Проверить, что по trace можно восстановить поведение агента
5. 📓 Зафиксировать основные failure modes

🎉 Критерии успеха
- ✅ Агент отправляет trace в LangSmith или легко подключается к нему по конфигу
- ✅ Есть понятный trace выполнения
- ✅ Можно визуально понять, где агент ошибся или зациклится
- ✅ Есть минимум 3 разобранных сценария
